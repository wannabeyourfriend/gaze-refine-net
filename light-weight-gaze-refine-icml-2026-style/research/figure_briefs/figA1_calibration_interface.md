## Why this figure
Reviewers want to see the actual UI and apparatus. Keep the old photographs
unchanged (they document the experimental setup) and add captions tying
each image to a specific phase.

## Layout
3 × 1 row of photographs:
1. Model fitting interface — 18-point grid on a 1920 × 1080 display, one
   point illuminated red.
2. Model testing interface — 32-point scattered grid.
3. Game testing interface — musical-note circles with one illuminated red.

Below the photo row, add a smaller 1 × 3 row of close-ups of the actual
hardware setup (Pupil Labs Core mount, participant seating, screen
distance) — these can come from old appendix Fig 10.

## Color & style
Photographs unmodified. Add a light grey border to each image and a small
phase label (Fitting / Testing / Game) above each photo in 8pt sans-serif.
